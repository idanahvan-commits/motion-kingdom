ממלכת התנועה — גרסה 11, מפת ממלכה משופרת

פתיחה מקומית:
1. חלצו את קובץ ה-ZIP לתיקייה אחת.
2. פתחו את index.html בדפדפן Chrome או Edge.
3. אפשר להשתמש במסך מלא באמצעות הכפתור העגול בתחתית המפה.

שליטה:
- לחצו על מתחם כדי להיכנס אליו.
- אפשר להזיז את מר פונקי בחצים; Enter מכניס למתחם סמוך.
- Esc מחזיר לממלכה.
- במתחמי הלימוד ההוראות מימין וההדגמה משמאל.
- במילון המונחים יש חיפוש.

לפרסום ב-GitHub Pages:
העלו את index.html, קובצי CSS ו-JavaScript, את maabedet_malbanim_interactive.html
ואת תיקיית assets כמות שהם, בשורש המאגר (או בתיקיית הפרסום שנבחרה).
ב-Settings > Pages בחרו main ו-/(root) ושמרו.

מה התחדש בגרסה 11:
- שיפור חדות התמונה המאושרת ללא שרטוט מחדש של הסצנה.
- רקע משודרג למסכי 16:9 תוך שמירה על כל הממלכה במלואה.
- מניעת החלפה פתאומית של כל הסצנה לתמונת JPEG מטושטשת בזמן הליכת הדמות.
- מפת התחנות, חדרי הלימוד, הטטריס והמילון נשארו זמינים.

חשוב: שיפור חדות וחישוב פיקסלים אינו יצירת פרטים חדשים במקור.
